# camera sdk wrapper(相机底层C++封装)

## 项目简历
本项目基于海康工业相机SDK进行C++面向对象二次封装。以应对原生SDK的C风格接口较多，直接调用易导致句柄泄漏与代码耦合。旨在提供一套健壮、简易相机驱动接口，简化上层视觉算法的图像采集流程。

## 技术栈
* **核心语言**：C++（面向对象编程、RAII资源管理思想、单例模式）
* **开发环境**：Linux(Ubuntu)
* **工程构建**：CMake
* **版本控制**：Git
  
  ## 核心特性与设计亮点
1.  **生命周期管理**：使用 `class` 封装了相机的完整生命周期（设备枚举 -> 创建句柄 -> 打开设备 -> 配置参数 -> 开始取流 -> 停止取流 -> 关闭设备 -> 销毁句柄）。
2.  **防御性错误处理**：针对不同层级的 SDK 返回值设计了分级异常处理机制。非核心参数设置失败予以忽略，核心操作（如打开设备、取流）失败则触发安全退出，确保程序不崩溃。
3.  **异常断连与重连**：在主循环中增加了对相机异常掉线的检测机制，并在异常分支中确保内存和句柄被正确释放，防止内存泄漏。
4.  **单例环境管理**：利用静态局部变量对 SDK 的全局运行环境进行单例式管理，确保环境初始化与销毁的安全。
